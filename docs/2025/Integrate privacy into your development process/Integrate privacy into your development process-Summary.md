# Integrate privacy into your development process

Integrate privacy into your development process https://developer.apple.com/videos/play/wwdc2025/246/



## ✨ 개요


이 세션은 기획 – 디자인 – 개발 – 테스트 – 배포 전 과정을 따라가며 , 앱을 만들 때 프라이버시를 어떻게 기본값 으로 설계할 것인지를 정리합니다 .

핵심 키워드는 데이터 최소 수집 , 온디바이스 처리 , 투명성 · 사용자 선택 , 보안입니다 .

🧱 프라이버시 개념 & 4 대 원칙

- 스티브 잡스의 정의 : “ 사람들이 자기가 무엇에 동의하는지 알 수 있게 , 쉬운 말로 , 반복해서 알려주는 것 .” 즉 , 사람 기대 ( 의도 ) 와 실제 데이터 사용이 일치해야 하고 , 그들이 스스로 선택할 수 있게 해야 합니 다 .

- Apple 이 쓰는 4 가지 프라이버시 기둥 :

- 데이터 최소 수집 (Data minimization) – 필요한 것만 , 필요한 만큼 .

- 온디바이스 처리 (On-device processing) – 가능하면 디바이스 밖으로 내보내지 않기 .

- 투명성 & 제어 (Transparency & control) – 무슨 데이터가 어떻게 쓰이는지 알려주고 , 끌 수 있는 스위치를 제공 .

- 보안 (Security protections) – 기술적으로도 데이터 흐름을 제한 ( 암호화 , E2E 등 ).



## 🗺 1. 계획 (Planning): “ 프라이버시 스토리 ” 쓰기


개발 초기에 프라이버시 보장 문장 (privacy assurances) 을 정의해서 “ 이 앱은 내 데이터를 이렇 게 다룬다 ” 를 한 문장씩 써 봅니다 .

  - 예시 앱 Pal About 기준 :

- 데이터 최소화 : “ 우리는 집계된 사용 데이터만 보관합니다 .”

- 위치 기본값 : “ 주변 검색 시 현재 위치는 기본적으로 저장하지 않습니다 .”

- 온디바이스 처리 : “ 모임 추천 장소는 온디바이스 데이터만으로 로컬에서 계산합니다 .”

- AI/ 학습 : “ 사진은 사용자가 ‘ 지능 향상에 동의 ʼ 했을 때만 모델 학습에 사용됩니다 .”

- 보안 : “ 친구에게 가는 메시지는 E2E 암호화되어 우리도 내용을 볼 수 없습니다 .” 🎨 2. 디자인 (Design): UI 로 신뢰 만들기 기대값을 선제적으로 설명 첫 실행 온보딩에서 핵심 데이터 사용 요약 + 자세히 보기 링크 제공 .

- 상태 변화는 눈에 보이게 Siri 활성화 애니메이션 , 마이크 사용 인디케이터처럼 , 데이터 흐름이 바뀌는 순간을 UI 로 보여 주기.

- 선택지는 의미 있고 맥락 있게 옵션 하나하나가 실제 동작을 바꾸거나 , 그 영향이 명확히 설명돼야 함 .

- 예 : 스트리밍 기기 연결 기능이 있을 때 , 그 기능을 눌렀을 때만 로컬 네트워크 접근 요청을 띄 우기 .

  - 더 자세한 UX 가이드는 Human Interface Guidelines( 프라이버시 섹션 ) 참고 권장 .

- 🛠 3. 개발 (Development): “ 적게 요청하고 , 맥락 있게 ” 📸 데이터 최소 액세스를 도와주는 UI 컴포넌트

- PhotosPicker 전체 사진 라이브러리 권한 없이 사용자가 고른 사진만 앱으로 들어오게 함 → 시스템이 Out-

  - of-process 로 렌더링 .

  - 따라서 포토 권한 프롬프트 자체를 건너뛸 수 있음( 선택한 사진만 전달 ).

- Location Button 버튼 탭 → 시스템이 사용자의 실제 탭을 검증 후 위치 공유 .

  - 첫 탭에는 설명 + 권한 프롬프트 , 이후에는 추가 프롬프트 없이 바로 위치 공유.

- 이외에도 : 연락처 피커 , UIPasteControl, 액세서리 설정 플로우 등 “ 필요한 것만 선택 ” 방식의 UI 도구들이 제공됩니다 .

- 🔑 권한 프롬프트 베스트 프랙티스 앱 첫 실행에 권한 폭탄 금지 .

- 사용자가 기능을 사용하려는 그 순간에 , 왜 필요한지 목적 문자열과 함께 보여주기 .

- 🔐 서버와 통신할 때의 프라이버시 도구 CloudKit + Advanced Data Protection CloudKit 에서 EncryptedString 등 암호화 타입을 사용하고 encryptedValues API 로 읽고 쓰면 , ADP( 고급 데이터 보호 ) 활성 시 앱 데이터도 E2E 암호화 혜택을 받습니다 .

- 단 , 암호화 필드는 인덱싱 / 쿼리 조건에 쓸 수 없음에 주의 .

- 동형암호 & PIR(Private Information Retrieval)

- 동형암호: 암호화된 데이터 위에서 연산 → 결과를 복호화하면 평문에서 계산한 것과 동일 .

- PIR: 서버는 질의 / 응답의 평문을 전혀 모른 채 DB 조회를 도와줌 .

- 디바이스가 암호화된 질의를 보내고 , 서버는 동형암호로 암호화된 결과를 계산한 뒤 돌려줌 .

- Pal About 예시 : “ 모임 장소 추천 ” 을 서버에 PIR 로 조회하면 , 서버는 사용자가 어떤 장소를 봤는지 모름 .

- 사기 방지 & 광고 측정 Private Access Tokens “ 이 요청이 진짜 기기에서 왔다 ” 는 것을 인증하면서도 , 개인을 식별하지 않음.

- DeviceCheck 디바이스당 2 비트 상태만 저장해서 “ 이 기기에서 프로모션 이미 썼다 ” 같은 검사 가능 ( 별도 ID 없이 ).

- AdAttributionKit 앱 설치 / 재참여를 캠페인에 귀속시키면서도 , ATT 프롬프트 없이 동작하도록 설계된 프레임워 크 .

광고 표시 앱은 Info.plist 에 네트워크 ID 추가 + 서명된 광고 노출 ,

- 광고 대상 앱은 전환 이벤트 등록 + 포스트백 수신 엔드포인트 설정.

- 💻 로컬 리소스 & 프로세스 관리

- Core ML: 가능한 한 온디바이스 추론 / 파인튜닝으로 서버 의존 · 데이터 유출 최소화 .

- 앱 그룹 컨테이너 여러 앱 / 익스텐션이 공유하되 , macOS 에선 다른 앱은 사용자 허용 없이는 접근 불가.

- macOS Tahoe 의 프로세스 정리 fork/exec/spawn 으로 띄운 하위 프로세스가 앱 종료 후에도 돌아가면 , macOS 가 이를 감지 해 사용자에게 종료 여부를 묻습니다 .

- 개발자는 앱 종료 시 자식 프로세스 정리 책임이 있습니다 .

- 서드파티 SDK 책임 포함된 모든 SDK 의 코드 · 데이터 수집에 앱 개발자가 책임.

- SDK 는 프라이버시 매니페스트가 필요할 수 있으며 , 앱 빌드의 “Generate Privacy Report” 로 한 번에 확인 가능 .



## 🧪 4. 테스트 (Testing): “ 프라이버시 회귀 테스트 ” 만들기


- 테스트 피라미드에 프라이버시도 포함 :

- Unit Test: opt-in/opt-out 플래그에 따라 데이터 전송이 바뀌는지 확인 .

- Integration Test: 시스템 간 데이터 플로우가 정의된 경로만 사용하는지 .

- UI Test: 온보딩 / 설정 화면에서 사용자가 옵션을 바꿨을 때 실제 네트워크 / 저장 동작이 기대와 일치하는지 .

- App Privacy Report(iOS 15.2+) 설정 > 앱 개인정보 리포트로 실제 데이터 / 센서 / 네트워크 접근 로그를 확인해 “ 우리가 약속한 것과 같은가 ?” 검증 .

- 🚀 5. 배포 (Deployment): 프라이버시 스토리 공개하기 App Store 개인정보 영양 정보 (App Privacy Nutrition Label) 앱이 디바이스 밖으로 보내는 데이터 종류 · 용도를 요약해 표시 .

- 실제로 수집할 ‘ 가능성 ʼ 이 있는 건 모두 포함해야 하며 , 일부 예외 ( 특정 피드백 / 리포트 용도 ) 는 문서 참고 .

- Xcode 아카이브에서 “Generate Privacy Report” 를 실행해 , 앱 + 모든 SDK 의 프라이버시 매니페스트 내용이 라벨과 일치하는지 확인 .

- 추가 요구사항 명확한 프라이버시 정책 문서 모든 퍼미션에 대한 purpose string 필요 시 App Store 에 Privacy Choices 링크( 데이터 열람 / 삭제 / 수정 포털 등 ) 제공 .

- 온보딩 ·UI 에서 데이터 사용을 미리 설명하고 , 상태 변화 ( 녹음 / 위치 등 ) 는 시각적으로 표시

- PhotosPicker·LocationButton 등 스코프 제한 UI 우선 사용 , 권한 프롬프트는 기능 사용 순간에

- Core ML· 온디바이스 모델 · 앱 그룹 컨테이너를 활용해 데이터를 최대한 디바이스 안에서 처리
