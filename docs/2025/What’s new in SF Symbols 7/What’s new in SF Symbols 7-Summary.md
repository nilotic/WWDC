# WWDC25 세션 337 — What’s new in SF Symbols 7 요약

---

<br>

## ✨ 개요

* 이번 세션은 **SF Symbols 7의 핵심 업데이트**를 소개합니다.
* 가장 큰 변화는 네 가지입니다.
  * **Draw**: 손으로 그리듯 심볼 경로를 따라 그려지는 새 애니메이션
  * **Variable Draw**: 색이 아니라 “그려진 정도”로 진행률을 표현하는 방식
  * **Gradients**: 심볼에 깊이감과 입체감을 더하는 새 렌더링
  * **Magic Replace 개선**: 관련 심볼 간 전환을 더 자연스럽게 연결
* 또한 세션 후반에는 **커스텀 심볼에 Draw를 주석(annotation)하는 방법**과 **SwiftUI / UIKit / AppKit API 사용법**까지 함께 다룹니다.

<br>

## ✍️ Draw: 새 애니메이션 시스템

* **Draw**는 SF Symbols 7에서 새롭게 추가된 애니메이션/렌더링 개념입니다.
* 심볼이 단순히 나타나거나 사라지는 것이 아니라, **정의된 경로를 따라 직접 그려지는 것처럼** 표현됩니다.
* 새 프리셋은 두 가지입니다.
  * **Draw On**: 심볼이 화면에 그려지며 등장
  * **Draw Off**: 심볼이 경로를 따라 지워지며 퇴장
* Draw는 심볼의 레이어 구조를 활용해, 단순한 페이드보다 훨씬 표현력이 좋습니다.
* 예를 들어 바람, 화살표, 문자 같은 심볼은 **의미에 맞는 방향성**으로 그려질 수 있어, 움직임 자체가 의미 전달에 참여합니다.

<br>

## ▶️ Playback 옵션과 표현 방식

* Draw On / Draw Off는 기존 symbol effect처럼 여러 playback 방식을 지원합니다.
* 주요 옵션은 다음과 같습니다.
  * **By Layer**: 각 레이어가 약간씩 시차를 두고 그려짐
  * **Whole Symbol**: 전체 레이어가 동시에 시작/종료
  * **Individually**: 각 레이어가 하나씩 순서대로 완전히 그려짐
* Draw Off에는 추가로 **reverse** 개념이 있어,
  * 원래 draw 방향대로 지울지
  * 반대로 되감듯 지울지
  선택할 수 있습니다.
* 덕분에 단순한 등장/퇴장뿐 아니라 **강조, 안내, 의도적인 시선 유도**에도 활용할 수 있습니다.

<br>

## 📈 Variable Draw

* SF Symbols에는 기존에도 **Variable Color**가 있어 색의 양으로 강도나 진행률을 표현할 수 있었습니다.
* SF Symbols 7에서는 여기에 더해 **Variable Draw**가 추가되었습니다.
* Variable Draw는 심볼 전체를 색으로 채우는 대신,
  * 경로의 일부만 실제로 그려 보여주고
  * 나머지는 낮은 불투명도로 남겨
  **진행률 자체를 경로 길이로 표현**합니다.
* 이런 방식은 특히
  * 다운로드 진행률
  * 온도 변화
  * 운동/활동 완료 상태
  같은 UI에 잘 어울립니다.
* 하나의 심볼이 **Variable Color와 Variable Draw를 모두 지원**할 수는 있지만, 실제 렌더 시점에는 둘 중 하나만 선택됩니다.

<br>

## 🔁 Magic Replace 개선

* 이번 버전에서는 **Magic Replace**도 더 똑똑해졌습니다.
* 두 심볼이 같은 **enclosure(공통 외곽/테두리 구조)** 를 공유하면,
  * 공통 부분은 유지하고
  * 다른 레이어만 교체해서
  더 자연스러운 전환을 만듭니다.
* 여기에 **Draw On / Draw Off**가 결합되면서,
  * 나가는 심볼은 Draw Off
  * 들어오는 심볼은 Draw On
  방식으로 연결될 수 있습니다.
* 즉 이제 Magic Replace는 단순 morph가 아니라,
  **공통 구조 보존 + Draw 기반 전환**까지 포함하는 더 연속적인 애니메이션 경험을 제공합니다.

<br>

## 🌈 Gradients

* SF Symbols 7에는 **Gradient 렌더링**이 새로 추가되었습니다.
* 단일 소스 색상으로부터 **부드러운 선형 그라디언트**를 자동 생성해, 평면적인 심볼에 조명감과 입체감을 더합니다.
* 이 기능은
  * 시스템 색상
  * 커스텀 색상
  모두 지원합니다.
* 또한 **모든 렌더링 모드 전반**에서 사용할 수 있고, **커스텀 심볼에도 적용**할 수 있습니다.
* 작은 아이콘에서도 동작하지만, Apple은 특히 **더 큰 크기에서 깊이감과 시각적 강조가 두드러진다**고 설명합니다.

<br>

## 🛠️ 커스텀 심볼에 Draw 주석 달기

* 세션의 큰 비중은 **커스텀 심볼을 Draw 가능하게 만드는 annotation 작업**에 할애됩니다.
* Draw는 단순 stroke 애니메이션이 아니라, 심볼 내부에 배치한 **guide point**를 기준으로 경로를 계산합니다.
* 최소 요구사항은 다음과 같습니다.
  * **시작점(start point)**
  * **끝점(end point)**
* 복잡한 심볼은 중간에 더 많은 guide point가 필요합니다.
* 이 guide point를 통해 시스템은
  * 어디서 시작할지
  * 어떤 방향으로 갈지
  * 어떤 코너를 어떻게 통과할지
  계산합니다.
* 즉 좋은 Draw 결과를 얻으려면, 심볼의 모양 자체뿐 아니라 **그 모양이 어떻게 그려져야 하는지**까지 설계해야 합니다.

<br>

## 🧭 Guide Point와 고급 설정

* 단순 선형 심볼은 guide point 두 개로도 충분하지만, 복잡한 심볼은 더 정교한 설정이 필요합니다.
* 세션에서 소개한 주요 개념은 다음과 같습니다.
  * **추가 guide point**: 급격한 굴곡이나 긴 경로 보정
  * **bidirectional draw**: 중심에서 양쪽으로 퍼져나가는 형태
  * **adaptive end cap**: 애니메이션 끝 모양을 실제 path 스타일과 맞춤
  * **multiple subpaths 지원**: 하나의 레이어 안 여러 경로 처리
  * **attachment**: 화살촉처럼 선을 따라 움직여야 하는 별도 요소 연결
  * **corner point**: 날카로운 꺾임을 자연스럽게 돌기 위한 특수 포인트
* 특히 화살표처럼 **선과 머리 부분이 따로 존재하는 구조**는 attachment를 잘 설계해야, 선이 그려질 때 화살촉도 함께 자연스럽게 따라옵니다.

<br>

## ⚖️ Weight 보간과 커스텀 심볼 제작 팁

* 커스텀 심볼 annotation은 **Regular weight**를 기준으로 시작합니다.
* guide point 추가/삭제는 기본적으로 이 weight에서 하고,
  시스템이 이를 바탕으로 **Ultralight / Black 템플릿으로 보간**합니다.
* 중요한 점은 각 weight에서 **연결된 guide point의 순서가 일관되어야 한다**는 것입니다.
* 이를 맞추지 않으면 weight가 바뀔 때 Draw가 어색해질 수 있습니다.
* 세션에서는 guide point 번호 표시 기능으로 순서를 점검하고, 필요한 포인트만 직접 덮어써서 보정하는 흐름을 보여줍니다.
* 또한 모든 심볼은 **9개 weight, 3개 scale** 조합에서 자연스럽게 동작해야 하므로, 최종적으로는 전체 구성에서 꼭 확인해야 합니다.

<br>

## 🧪 Variable Draw를 위한 레이어 선택

* Draw annotation을 마쳤다고 해서 모든 레이어가 Variable Draw에 자동 참여하는 것은 아닙니다.
* 개발자는 어떤 레이어가 Variable Draw에 반응할지 선택할 수 있습니다.
* 예를 들어 thermometer 같은 심볼에서는,
  * 테두리 전체가 아니라
  * 내부 게이지만 Variable Draw에 참여하게 하여
  **실제 진행률 의미가 있는 부분만 변화**하도록 만들 수 있습니다.
* 이 선택이 중요하기 때문에, Apple은 각 레이어를 검토하면서 의도적으로 활성화하라고 안내합니다.

<br>

## 💻 새로운 API

* SF Symbols 7 기능은 코드에서도 비교적 간단히 사용할 수 있습니다.
* **Draw 애니메이션**은 기존 패턴처럼 `symbolEffect`를 사용해 적용합니다.
  * SwiftUI에서는 상태값 변화에 따라 Draw On / Off 애니메이션을 줄 수 있습니다.
  * UIKit / AppKit에서도 각각 대응되는 방식으로 trigger할 수 있습니다.
* **Variable Draw**는 관련 설정에서 **variable value mode**를 지정하고, 원하는 값으로 심볼 상태를 구성합니다.
* **Gradient 렌더링**은
  * SwiftUI에서는 view modifier
  * UIKit / AppKit에서는 symbol configuration
  으로 설정할 수 있습니다.
* SF Symbols 앱의 **Copy Code** 기능을 이용하면, 앱에서 미리 본 설정을 코드로 옮기기 더 쉽습니다.

<br>

## ✅ 정리

* SF Symbols 7의 핵심은 단순히 아이콘이 늘어난 것이 아니라, **심볼이 표현하는 방식 자체가 확장**되었다는 점입니다.
* Draw는 심볼을 더 생동감 있게 만들고,
  Variable Draw는 진행률 표현을 더 직관적으로 바꾸며,
  Gradients는 입체감과 강조를 더하고,
  Magic Replace 개선은 상태 전환을 더 매끄럽게 만듭니다.
* 특히 커스텀 심볼까지 이 기능을 활용할 수 있게 되면서,
  앱 고유의 아이콘 체계에서도 **Apple 시스템 심볼 수준의 애니메이션과 표현력**을 구현할 수 있게 되었습니다.
* 실무적으로는 먼저 **SF Symbols 7 앱에서 직접 미리보기와 annotation 실습**을 해보고, 이후 SwiftUI / UIKit 코드에 단계적으로 적용하는 흐름이 가장 좋습니다.
