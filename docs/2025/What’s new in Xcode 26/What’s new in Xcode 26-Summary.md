# WWDC25 세션 247 — What’s new in Xcode 26 요약

<br>
## ✨ 개요

* 이번 세션은 **Xcode 26의 생산성·성능·지능형 개발 경험 업데이트**를 한 번에 정리하는 세션입니다.
* 큰 흐름은 여섯 가지입니다.
  * **다운로드 크기와 로딩 성능 최적화**
  * **워크스페이스와 에디터 경험 개선**
  * **Playground와 Icon Composer**
  * **지능형 개발 보조 기능**
  * **디버깅·성능 분석·빌드 개선**
  * **테스트 경험 강화**
* 전체적으로는 Xcode가 단순 IDE를 넘어, **더 빠르고 더 똑똑하며 더 실험적인 개발 환경**으로 확장된 것이 핵심입니다.

<br>
## ⚡ 최적화: 더 작고 더 빠른 Xcode

* 올해 Xcode는 설치와 실행의 기본 경험부터 개선되었습니다.
* 세션 기준으로 Xcode 26은 **이전보다 24% 더 작아졌고**, workspace 로딩은 **최대 40% 더 빨라졌습니다.**
* simulator runtime은 기본적으로 Intel 지원을 포함하지 않고, Metal toolchain도 필요한 프로젝트에서만 내려받도록 바뀌었습니다.
* 복잡한 표현식을 입력할 때의 typing latency도 일부 경우 **최대 50%까지 줄어들었다고** 소개됩니다.
* 즉, 설치 용량·실행 속도·타이핑 반응성이 모두 개선되어 대형 프로젝트일수록 체감 차이가 커지는 방향입니다.

<br>
## 🗂️ 워크스페이스와 에디터 개선

* 에디터 탭 동작이 더 직관적으로 바뀌었습니다.
* Safari처럼 새 탭을 열고 시작 페이지에서 원하는 파일로 이동할 수 있고, **pin tab** 으로 특정 파일을 고정할 수도 있습니다.
* 검색 기능도 크게 좋아졌습니다.
* 새 **Multiple Words search** 는 여러 단어가 가까이 모여 있는 클러스터를 찾아, 프로젝트 전체에서 관련성이 높은 문서를 우선 정렬해 보여줍니다.
* 단어 순서가 달라도 되고 여러 줄에 걸쳐 있어도 찾을 수 있어, 낯선 코드베이스를 탐색할 때 특히 유용합니다.
* 접근성 쪽에서는 **Voice Control용 Swift mode** 가 추가되었습니다.
* 자연스럽게 Swift 코드를 읽듯이 말하면,
  * 공백 처리
  * camelCase
  * 연산자 해석
  등을 시스템이 이해해 실제 Swift 코드를 입력할 수 있습니다.

<br>
## 🧪 Playground: 코드 탐색과 실험 흐름 강화

* 올해 새 기능 중 하나가 **`#Playground` 매크로**입니다.
* 기존 Preview처럼 문서 안에 inline으로 playground를 만들고, 실행 결과를 canvas에서 바로 확인할 수 있습니다.
* 장점은 UI 코드뿐 아니라 **일반 로직, 데이터 구조, 정규식, 파싱 결과**까지 빠르게 실험할 수 있다는 점입니다.
* 세션 데모에서는 landmark 좌표 버그를 playground로 추적하며,
  * 샘플 데이터 로딩
  * Quick Look 확인
  * 정규식 매칭 범위 시각화
  * 수정 후 즉시 재실행
  같은 흐름을 보여줍니다.
* 즉 Playground는 단순한 학습 도구가 아니라, **디버깅·분석·프로토타이핑을 위한 실전용 도구**로 자리 잡았습니다.
* Apple은 이 `#Playground` 경험도 오픈소스로 확장한다고 소개합니다.

<br>
## 🎨 Icon Composer와 리소스 제작 흐름

* **Icon Composer** 는 Xcode 26에 함께 포함되는 새 앱입니다.
* 하나의 파일 안에서 여러 플랫폼과 여러 모드에 대응하는 아이콘을 설계할 수 있도록 만들어졌습니다.
* 특히 올해는 아이콘이 플랫폼뿐 아니라
  * light / dark / tinted 모드
  * watchOS의 새 스타일
  에도 대응해야 하므로, 관리 복잡도가 커졌는데 이를 한 도구 안에서 정리해 줍니다.
* blur, shadow, specular highlight, translucency 같은 레이어 속성도 지원해, 더 풍부한 아이콘 표현이 가능합니다.
* 동시에 예전 OS나 웹용의 flat icon도 함께 만들 수 있어, **멀티 플랫폼 아이콘 제작 파이프라인을 통합**하는 의미가 큽니다.

<br>
## 🌍 현지화와 문자열 카탈로그 개선

* 현지화 흐름도 실용적으로 강화되었습니다.
* 세션에서는 **String Catalogs** 가 더 좋아졌다고 설명하며, 개발자와 번역가 모두를 위한 개선을 소개합니다.
* 특히 개발자 입장에서는 **localized string에 대한 타입 안전한 Swift 심볼**이 추가되어, 문자열 키를 더 안전하게 다룰 수 있게 됩니다.
* 즉 문자열 리소스를 단순 텍스트가 아니라 **컴파일 타임에 더 안전하게 연결되는 자산**처럼 다루는 방향입니다.

<br>
## 🤖 Intelligence: LLM을 개발 워크플로에 통합

* Xcode 26의 가장 큰 변화 중 하나는 **대규모 언어 모델(LLM)을 개발 흐름 안으로 끌어들인 것**입니다.
* 세션 페이지 요약에서도 이 부분을 핵심 축으로 강조합니다.
* 올해 Xcode는 코드 작성과 탐색 과정에서 모델 기반 지능 기능을 활용할 수 있도록 확장되었습니다.
* 단순 자동완성을 넘어서,
  * 코드 이해 보조
  * 편집 작업 가속
  * 개발 문맥 기반 지원
  으로 방향이 넓어졌다는 점이 중요합니다.
* 즉 Xcode는 이제 **개발자가 직접 모든 것을 찾아가는 도구**에서, **문맥을 읽고 함께 작업하는 도구**로 이동하고 있습니다.

<br>
## 🐞 디버깅과 성능 분석

* 세션 후반부는 **디버깅과 성능 분석** 개선에 초점을 맞춥니다.
* Apple은 올해 Xcode 26이 debugging, performance workflow를 더 빠르고 실용적으로 만들었다고 설명합니다.
* 단순히 앱을 실행하고 로그를 읽는 수준이 아니라,
  * 병목 구간 찾기
  * 전력 사용 분석
  * 보안 설정 점검
  * SwiftUI 성능 이해
  같은 작업을 더 자연스럽게 이어서 할 수 있게 했습니다.
* 관련 리소스로 Processor Trace, Power Profiler, SwiftUI performance 자료도 함께 연결하며, **프로파일링 중심 개발 흐름**을 강조합니다.

<br>
## 🏗️ 빌드 시스템과 Swift Build

* Xcode 26의 또 다른 핵심은 **Swift Build** 입니다.
* 세션 설명에 따르면 Swift Build는 **Xcode가 사용하는 오픈소스 빌드 시스템 엔진**입니다.
* 이는 단순 내부 구현 공개가 아니라,
  * 빌드 동작 이해
  * 도구 체인 확장
  * 더 투명한 빌드 인프라
  로 이어질 수 있는 변화입니다.
* 즉 Xcode의 빌드 경험이 점점 더 **개방적이고 공유 가능한 기반** 위에 놓이기 시작했다는 의미가 있습니다.

<br>
## ✅ 테스트 경험 강화

* 마지막 축은 **Testing** 입니다.
* 세션은 Xcode 26이 테스트 흐름도 개선했다고 정리합니다.
* 구체적으로는 개발 중 테스트를 더 자주 돌리고, 문제를 더 빨리 발견하고, 반복 실행 부담을 줄이는 방향의 개선이 이어집니다.
* 전체 맥락상 Xcode 26의 테스트 업데이트는 에디팅·디버깅·빌드 개선과 함께, **개발 루프 전체를 짧게 만드는 요소**로 보는 것이 맞습니다.

<br>
## ✅ 정리

* Xcode 26은 설치 용량과 성능 최적화부터, 에디터·검색·접근성·실험 도구·아이콘 제작·LLM 기반 개발 지원까지 전반적으로 크게 확장된 업데이트입니다.
* 핵심만 다시 보면
  * 더 작고 빠른 Xcode
  * Multiple Words search와 Voice Control용 Swift mode
  * `#Playground` 매크로
  * Icon Composer
  * LLM 통합 개발 경험
  * 디버깅·성능 분석·Swift Build·테스트 강화
  가 큰 축입니다.
* 전체적으로 보면 이번 업데이트는
  **“Xcode를 더 빠른 IDE에서, 탐색·실험·분석·생성까지 모두 아우르는 개발 플랫폼으로 진화시키는 변화”** 라고 볼 수 있습니다.
